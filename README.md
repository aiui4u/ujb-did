# 의정부시 통합현황

기존 의정부시 통합 DID 화면을 GitHub Pages용으로 변환한 초기 업로드 파일입니다.

- `web/`: 게시할 정적 웹페이지입니다. 이 폴더를 통째로 유지합니다.
- `web/data.json`: 현재 저장된 날씨·인구·출생·상권·교통 자료입니다.
- `web/news.json`: Google RSS 뉴스 자료입니다. 시청 보도자료 HTML 수집은 제외합니다.
- `source/ujb-did-source.zip`: 화면 수정을 위한 원본 소스 보관본입니다.

공약사항과 사업 상세보기, 공약 도면, 기존 메뉴 및 디자인을 유지했습니다.
날씨는 의정부시청 대표 격자만 표시하며 지역 선택은 제거했습니다.
인구 메뉴의 15개 동 비교는 유지합니다.

이 파일을 올리는 단계에서는 자동 수집이 아직 설정되지 않습니다.
다음 단계에서 Pages 배포와 GitHub Actions 수집기 및 Secrets를 설정합니다.
인증키는 소스나 JSON에 입력하지 않습니다.

소스 수정: source 압축을 풀고 Node.js 24에서 `npm install`, `npm run build`를 실행하면 web 폴더가 생성됩니다.
